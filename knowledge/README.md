# База знаний

Помещайте сюда `.md` или `.txt` файлы с информацией, которой должен пользоваться бот.

Примеры:

- `company.md` — информация о компании;
- `products.md` — товары и услуги;
- `faq.md` — частые вопросы;
- `rules.md` — правила общения.

На каждом запросе бот извлекает наиболее релевантные фрагменты из этой папки и передаёт их модели вместе с системным промтом.
